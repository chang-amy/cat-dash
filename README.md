# 🐾 Cat Dash

A tiny one-button, Geometry-Dash-style street parkour game. Miso the cat is late
for dinner — jump traffic cones, trash cans and hydrants, bounce off crates,
snag fish, and make it 100% of the way home through the dusk city.

## Run it

Open `index.html` in any modern browser (double-click it, or `open index.html`
on a Mac). No build step, no server, no dependencies.

## Controls

| Input | Action |
|---|---|
| Space / Click / Tap | Jump |
| Hold | Longer, higher jumps — and auto-bounce on landing |
| R | Instant restart |
| M / 🔊 button | Mute |
| Esc / P | Pause |

## Tips

- Obstacles come in all sizes — squat cones, tall cones, little bins, big bins.
- Tap for a quick hop; hold Space longer to float higher and cover more ground.
- You can land on top of crates (they stack 1–3 high) — side hits are fatal.
- Hitboxes are forgiving, just like the spikes in Geometry Dash.
- Fish are for bragging rights (they add up across runs).
- Beat the level and the streets speed up: Lv 2, Lv 3...
- Best %, total fish and attempt count are saved in your browser.
